# Dyne Right Website

This is the Dyne Right single-page React site (Vite + Tailwind).

## Local dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
# output goes to /dist
```

## Deploy on Vercel
- Import this repo in Vercel
- Build Command: `npm run build`
- Output Directory: `dist`
- Add your domain in Vercel → Settings → Domains
